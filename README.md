# Rubout

Watermark remover for photos. Runs entirely on your device (nothing is uploaded). Installable on iPhone as a web app.

- **Auto**: a small neural net (U-Net, ~60k weights, plain JavaScript) finds watermarks, then a PatchMatch inpainter fills them in.
- **Manual**: brush / magic wand tools as a fallback.

Open the Pages link in Safari, tap Share, then "Add to Home Screen".
